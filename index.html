📸 Фото → 3D: загрузите 1–5 фото. Для 1–2 фото включите «ИИ-достройку 4 ракурсов».

✨ Текст → 3D: 6 стилей — Реализм, Киберпанк, Лоу-поли, Воксель, Винил, Стимпанк.

🎨 ИИ-Рендер: кнопка «✨ ИИ-Рендер» — фотореалистичный рендер с ползунком До/После.

📦 Экспорт: .GLB (с PBR для Blender/Unity/Unreal), .OBJ, .STL для печати, PNG и видео.

🔑 API-ключ: нажмите 🔑 в шапке и вставьте Gemini API Key с aistudio.google.com/apikey. Хранится только в вашем браузере.

⌨️ Горячие клавиши: Ctrl+Z — undo, Ctrl+Shift+Z — redo, Space — пауза анимации.

🔑 Gemini API Key

Получите бесплатный ключ на aistudio.google.com/apikey. Ключ хранится только в вашем браузере (localStorage) и отправляется только в Google API.
